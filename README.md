# Giftria 🎁

Giftria is a full-stack web application built with **Node.js, Express.js, MySQL, and EJS**. The application provides a secure admin panel for managing products, categories, and subcategories. It includes JWT-based authentication, image uploads, search functionality, session management, and a responsive user interface.

---

## 🚀 Features

- 🔐 JWT Authentication & Authorization
- 👨‍💼 Secure Admin Dashboard
- 📦 Product Management (Add, Update, Delete)
- 🗂️ Category & Subcategory Management
- 🔍 Search & Filter Functionality
- 🖼️ Image Upload using Multer
- 🗄️ MySQL Database Integration
- 💾 Local Storage for Token Management
- 📝 Session Management
- 🔒 Environment Variable Management using dotenv
- 🛡️ Protected Routes
- 📱 Responsive User Interface
- ❌ Error Handling

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/rajshakya12/Giftria.git
```

### Move to the project directory

```bash
cd Giftria
```

### Install dependencies

```bash
npm install
```

### Start the application

```bash
npm start
```

### Open in your browser

```text
http://localhost:3000
```
